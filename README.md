# 咕咕的小房间 · Guguland

一个可以放纸条、照片、声音和唱片的小房间。第三版包含浅卡其帽子、六首自选歌曲的唱片入口，以及独立的密码投递页。

## 当前状态

此仓库保存网站源码。上传 GitHub 不等于网站已上线。

当前后端支持本地 Node.js，以及 Cloudflare Worker + R2。**Vercel 后端和持久化存储适配尚未完成，请勿直接使用当前 build 命令在 Vercel 部署。** 当前 build 产物是 Worker，不是 Next.js 网站。

## 本地打开

安装 Node.js 22 或更新版本，在项目目录执行：

```sh
npm start
```

- 房间：http://127.0.0.1:8765/
- 投递口：http://127.0.0.1:8765/deliver
- 首次设置密码：http://127.0.0.1:8765/local-setup（仅本机）

Windows 也可双击 `启动小房间.cmd`。

## 目录

- `web/`：房间和投递页面。
- `server/api.mjs`：身份验证、投递、媒体和生日设置接口。
- `server/local.mjs`：本地运行和文件存储。
- `build.mjs`：生成 Cloudflare Worker，需另行配置 R2 的 `BUCKET` 绑定和 `SETUP_KEY` 密钥。

## 内容与隐私

仓库不包含本地密码、初始化密钥、私人投递或歌曲音频。歌单只是标题，需要在投递口上传对应音频才可播放。访问房间不记录已读或播放次数。房间布置、小本子及相框保存在各自浏览器中，不会跨设备同步；投递内容通过后台共享。

部署后的房间内容对能访问网址的人可见，投递操作需要密码。不要把初始化链接或真实密钥提交到 GitHub。
